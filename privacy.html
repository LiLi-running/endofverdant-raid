캐릭터시작 페이지

이 사이트는 커뮤니티 게임 진행에 필요한 최소한의 정보만 다룹니다. 실명, 이메일, 전화번호, 마스토돈 계정은 받지 않습니다.

1. 저장하는 정보

정보언제왜
익명 사용자 ID (무작위 문자열)처음 방문할 때 브라우저마다 자동 발급내 캐릭터·전투 참가·로그인 상태 구분
캐릭터 이름, 이미지 주소, 1:1 스탯, 레이드 포지션·정수 분배캐릭터를 만들거나 수정할 때게임 진행과 화면 표시

레이드 게임 기록과 로그인 상태레이드 진행·로그인레이드 진행

그 밖에 테마 선택, 마지막으로 들어간 레이드 게임, 섬전에서 고른 캐릭터, 로그인 유지 정보가 사용 중인 브라우저 안에만 저장됩니다. 서버로는 보내지 않습니다.

2. 비밀번호

  • 캐릭터·레이드 비밀번호는 원래 글자를 저장하지 않고, 되돌릴 수 없는 해시(SHA-256)로만 저장합니다. 관리자도 원래 비밀번호를 볼 수 없습니다.
  • 비밀번호를 잊으면 관리자가 새 비밀번호로 재설정해 드릴 수 있습니다.
  • 짧거나 흔한 비밀번호는 해시라도 추측될 수 있습니다. 다른 사이트에서 쓰는 비밀번호는 사용하지 마세요.

3. 누가 볼 수 있나

대상볼 수 있는 정보
모든 방문자캐릭터 이름·이미지·스탯·레이드 설정, 달러와 섬전 점수·출석 시각(순위), 1:1 전투방과 전투 기록
레이드 게임 코드를 아는 사람그 게임의 캐릭터 상태와 진행 기록
본인 브라우저위 정보 + 이 브라우저에 등록한 캐릭터 목록
사이트 관리자위 정보 + 레이드 게임 목록, 비밀번호 해시(원래 비밀번호는 볼 수 없음), 기기 등록 목록
Firebase 프로젝트 소유자저장된 모든 데이터와 익명 계정 목록(생성·최근 접속 시각)

익명 ID만으로는 누구인지 알 수 없지만, 같은 브라우저로 참가한 전투들은 같은 ID로 이어져 보입니다.

4. 사용 범위와 보관

  • 저장한 정보는 본인 확인, 전투·레이드 진행, 순위 표시에만 씁니다. 분석 도구, 광고, 외부 제공은 없습니다.
  • 정보는 자동으로 지워지지 않습니다. 캐릭터 페이지에서 직접 캐릭터를 삭제하면 캐릭터, 비밀번호 해시, 지갑이 함께 지워집니다. 이미 진행된 전투·레이드 기록은 남습니다.
  • 기록 삭제를 원하시면 관리자에게 요청해 주세요.

5. 사이트 밖의 서비스

페이지를 열 때 아래 서비스가 방문자의 IP 주소와 브라우저 정보를 받습니다. 각 서비스의 정책을 따르며, 이 사이트에서 막을 수 없습니다.

  • GitHub Pages (사이트 호스팅)
  • Google Firebase (데이터 저장·익명 로그인), Google Fonts (글꼴)
  • jsDelivr (Pretendard 글꼴), Tailwind CDN (레이드·관리자 화면 스타일)
  • 캐릭터·보스 이미지가 올라가 있는 사이트 (imgur 등, 이미지 주소의 호스트)

궁금한 점이나 삭제 요청은 녹채반역 운영진에게 문의해 주세요.
